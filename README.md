# Service Request Research Demo

Minimal individual research project for the Capstone Research Milestone. It demonstrates login, request creation/filtering/removal/completion, and scheduled requests in a calendar.

## Run locally

Create database: `CREATE DATABASE service_demo;`

Start API: `mvn spring-boot:run` (Swagger: http://localhost:8080/swagger)

Start UI: `cd frontend; npm install; npm run dev`

Login with `demo` / `demo`.

## Technologies tested

Next.js/React, Tailwind, FullCalendar, Spring Boot, Spring Security, JWT dependencies, Spring Data JPA/Hibernate, Flyway, Springdoc/Swagger, JUnit/Mockito, and MySQL.
